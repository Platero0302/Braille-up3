# BRAILLE UP! — Software acessível

Esta versão foi redesenhada para acessibilidade desde o início.

## Recursos
- letras grandes por padrão;
- botões grandes;
- navegação por teclado;
- foco visual forte;
- controle A− / A+ para tamanho das letras;
- alto contraste;
- áudio em português;
- opção de falar cada tecla digitada;
- regiões ARIA live;
- interface responsiva;
- conexão opcional com Arduino via Web Serial.

## Executar
```bash
npm install
npm run dev
```

## Arduino
1. Grave o firmware BrailleUP_Arduino.ino no Arduino.
2. Conecte o Arduino por USB.
3. Abra o Braille UP! em Chrome ou Edge no computador.
4. Clique em Conectar Arduino.
5. Selecione a porta.
6. Acesse Aprender letras e escolha uma letra.
